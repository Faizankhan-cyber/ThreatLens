# ThreatLens

### Is that link safe — or a trap?

ThreatLens is a digital threat detection platform designed to help users identify suspicious links, phishing attempts, scams, and other potentially harmful digital content before interacting with them.

The project was created as a **hackathon project by Cloud Sentinals**, a team of BCA students focused on cybersecurity, digital safety, and practical technology solutions.

## 🎯 The Problem

Online scams and phishing attacks are becoming harder to recognize.

Attackers commonly use:

- Fake banking messages
- UPI payment scams
- KYC verification scams
- Fake delivery notifications
- Malicious links
- Social engineering
- Fake login pages
- Suspicious emails and messages

For many users, it can be difficult to determine whether something is legitimate before clicking a link or sharing information.

ThreatLens aims to make that first security check simple and accessible.

---

## 💡 Our Solution

ThreatLens provides a centralized digital safety interface where users can submit suspicious content and analyse it before interacting with it.

The platform is designed around a simple workflow:

```text
Submit suspicious content
        ↓
Threat analysis
        ↓
Risk identification
        ↓
Understand the threat
        ↓
Make a safer decision
```
The goal is to make digital threat detection easier to understand without overwhelming users with complicated security terminology.

Use screenshots as an additional source of threat investigation.

# ⚙️ Run Locally

1. Clone the Repository

2. Open the Project
cd ThreatLens
3. Install Dependencies

4. Start the Development Server

# 🔐 Security Awareness

ThreatLens is designed to encourage safer behaviour when users encounter suspicious digital content.

Users should still follow basic security practices:

Never share OTPs
Never share passwords
Avoid entering banking credentials on unknown websites
Verify payment requests independently
Avoid opening suspicious links
Check the sender before trusting a message
Do not scan unknown QR codes without verification

Threat detection tools should support good security habits, not replace them.

# ⚠️ Disclaimer

ThreatLens is a hackathon project and security-awareness tool.

Its analysis should not be treated as an absolute guarantee that a URL, message, email, screenshot, QR code, or phone number is safe or malicious.

Always verify suspicious requests through trusted sources before taking action.
